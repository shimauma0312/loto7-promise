# テスト
```
test/
├── main_test.go           # テストのメインエントリーポイント
├── recommendation_test.go # 推薦機能のテスト
├── heatmap_test.go       # ヒートマップ機能のテスト
└── result_test.go        # 結果取得機能のテスト
```

## テスト実行方法

### 1. 全テスト実行
```bash
go test ./test/ -v
# または
make test
```

### 2. ユニットテストのみ実行
```bash
make test-unit
```

### 3. 統合テストのみ実行
```bash
make test-integration
```

### 4. パフォーマンステスト実行
```bash
make test-performance
```

### 5. ベンチマークテスト実行
```bash
make test-bench
```

## テストの特徴

### TestMain エントリーポイント
- 全テストの前後で準備・クリーンアップ処理を実行
- テスト実行時刻と結果サマリーを表示
- 統一されたテスト出力フォーマット

### 統合テスト
- 複数機能の連携動作を確認
- 結果取得 → ヒートマップ → 推薦の流れをテスト
- データ整合性チェック

### 各機能別テスト
- **recommendation_test.go**: 推薦アルゴリズムの動作確認
- **heatmap_test.go**: ヒートマップ生成と統計処理の確認
- **result_test.go**: 過去データ取得とフォーマットの確認

### エラーハンドリングテスト
- 不正入力に対する適切なエラー処理の確認
- 境界値テストの実施

### パフォーマンステスト
- 推薦生成のパフォーマンス計測
- メモリ使用量の監視

## テストデータ

- 実際のロト7過去データを使用（キャッシュ機能付き）
- テスト実行時に最新データを自動取得
- 小規模データセット（5-20回分）でパフォーマンス最適化

## 継続的インテグレーション対応

- `-timeout` オプションでタイムアウト設定可能
- `-short` フラグでパフォーマンステストのスキップ可能
- 各テストの独立性を保証

## トラブルシューティング

### データ取得エラー
```bash
# ネットワーク接続を確認
# キャッシュをクリア後再実行
```

### タイムアウトエラー
```bash
# タイムアウト時間を延長
go test ./test/ -v -timeout 5m
```

### 特定テストのみ実行
```bash
# 推薦機能テストのみ実行
go test ./test/ -v -run "TestRecommendation"

# ヒートマップテストのみ実行
go test ./test/ -v -run "TestHeatmap"
```
