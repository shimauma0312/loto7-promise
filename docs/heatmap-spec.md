# ヒートマップ
ロト7の数字がどの位置でよく出現するかを見える化する

## 処理フロー

### 分析の流れ
```
1. コマンド解析
   ├─ range, number, position, json オプション読み取り
   └─ デフォルト値設定

2. データ取得
   ├─ result.GetResult(range) 呼び出し
   └─ 指定回数分の抽選結果取得

3. ヒートマップ作成
   ├─ 37x7のマトリックス初期化
   ├─ 各抽選結果をループ処理
   │   └─ heatmap[数字][位置]++ でカウント
   └─ 合計値計算

4. 統計計算
   ├─ 最頻出数字の特定
   ├─ 最少出現数字の特定
   └─ 位置偏向度計算

5. 結果出力
   ├─ JSON形式 → JSON出力
   └─ テキスト形式 → 表形式出力
```

### 偏向度計算
```
各数字について:
1. 7つの位置での出現回数を取得
2. 標準偏差を計算
3. 最大の標準偏差を持つ数字が「最も偏向」
```

### データの整理方法
```
こんな感じの表を内部で作る:
- タテ軸: 数字（1〜37）
- ヨコ軸: 位置（1〜7番目）  
- 中身: 「その数字がその位置で出た回数」

統計情報:
- よく出る数字: 全体で一番多く出現した数字
- あまり出ない数字: 全体で一番少ない数字
- 偏りがすごい数字: 特定の位置にかたよって出る数字
```
## 使い方

### 基本的なコマンド
```bash
go run cmd/heatmap/main.go [オプション]
```

### 設定できること
| 設定 | 何を入れる | 説明 | 何も設定しないと |
|------|-----------|------|-----------------|
| `-range` | 数字 | 過去何回分を見るか | 50回分 |
| `-number` | 1-37 | 特定の数字だけ分析したい時 | 全部の数字 |
| `-position` | 1-7 | 特定の位置だけ見たい時 | 全部の位置 |
| `-json` | なし | JSON形式で出力したい時 | 普通の表形式 |

### 実際の使用例
```bash
# 過去50回分を全部分析（一番よく使うパターン）
go run cmd/heatmap/main.go -range=50

# 数字7に注目して過去100回分を分析
go run cmd/heatmap/main.go -number=7 -range=100

# 1番目の位置だけをJSON形式で出力
go run cmd/heatmap/main.go -position=1 -json
```

```
数字    位置1   位置2   位置3   位置4   位置5   位置6   位置7   合計
 1        2       1       0       1       0       0       1       5
 2        0       3       1       2       1       0       0       7
...

=== 統計情報 ===

```

### JSON形式（-jsonを付けた時）
```json
{
  "analysis_range": 50,
  "actual_draws": 50,
  "heatmap": {
    "1": {"pos1": 2, "pos2": 1, ...},
    "2": {"pos1": 0, "pos2": 3, ...},
    ...
  },
  "statistics": {

    "least_frequent": [あまり出ない数字のリスト],
    "most_biased": 一番かたよってる数字
  }

```

## 結果をどう読むか

### 表の読み方
- **数字が大きい**: その数字がその位置でよく出てる
- **0**: その数字がその位置では一回も出てない  
- **合計列**: その数字が全体でどのくらい出てるか

### 統計情報の活用法
- **よく出る数字**: 全体的に出現率が高い、人気の数字
- **あまり出ない数字**: 最近ご無沙汰している数字たち
- **かたよりがある数字**: 「いつもこの位置にいる」みたいな癖のある数字

## 注意事項

### データについて
- Result機能で取得済みのデータしか使えません
- 大量データの分析は初回だけちょっと時間がかかります
- 分析回数が少ないと、統計的にあまり意味がないかも
